# subluxe.ca

Personal site, hosted on GitHub Pages (Jekyll).

- **Profile text** (name line, likes/dislikes, currently, etc.) lives in one
  file: `_data/profile.yml` — edit that and the landing page updates.
- **About page:** `about.md`
- **Photos:** drop image files into `assets/img/photos/` and they appear on
  the Photos page automatically. The first three also show as "picks" on the
  landing page.
- **Writing:** add a Markdown file to `_posts/` named
  `YYYY-MM-DD-title.md` with `layout: post` front matter, or ask Muse to
  publish one. Posts appear in the Writing section and on the landing page.
- **Profile picture:** replace `assets/img/profile.png`, or put a new file at
  `assets/img/profile.jpg` and update `photo:` in `_data/profile.yml`.
